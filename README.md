# IGS-OS
AI-assisted independent game development operating system. Includes Unity framework, game design system, market research database, and automated development workflow powered by ChatGPT and Codex.一个基于AI（ChatGPT + Codex）的独立游戏开发操作系统，用于统一管理游戏设计、Unity开发、数值系统、市场分析、商业化与发布流程，实现从“想法 → 游戏 → 上线”的完整生产链路。
