# GameCompany

GameCompany is the top-level workspace for game design, Unity development, data management, tools, builds, and decision logging.

## Structure

```text
GameCompany/
├── README.md
├── .gitignore
├── docs/
├── design/
├── game/
├── data/
├── builds/
├── tools/
└── logs/
```

## Notes

- `docs/` stores research, plans, specs, and operational knowledge.
- `design/` stores gameplay rules, mechanics, and balancing design.
- `game/` is the only Unity development area.
- `data/` stores configuration tables and numeric tuning data.
- `builds/` stores exported builds when needed.
- `tools/` stores non-Unity scripts and helper utilities.
- `logs/` stores major decision records and change notes.
